# 未发送邮件：不存在的收件人

一款以旧电脑为入口的网页叙事解谜游戏。

你在母亲留下的旧物中发现了一把钥匙，以及一个从未听说过的地址——槐花市。来到那间无人居住的房子后，你打开了一台多年没有启动的电脑。邮件、聊天记录、旧论坛、校园网站和新闻档案散落在不同角落；只有将它们重新拼合，才能理解母亲从未讲述的过去。

> 有些邮件并不是没有寄出，只是它们等待了太久，收件人已经不存在了。

## 游戏类型

- 网页叙事解谜 / 互动小说
- 复古 Windows XP 桌面探索
- 多页面线索搜集与密码推理
- 非线性信息阅读与故事还原

## 玩法

玩家将在模拟的旧电脑中自由探索 Outlook Express、QQ、QQ 空间、浏览器、校园网站、论坛和公共档案等页面。不同页面中的日期、人物、文字和图片会相互印证，并共同指向后续密码和剧情。

- 单击或双击桌面图标打开应用；
- 阅读邮件、聊天记录、网页和档案，记录人物与时间线；
- 结合多个线索推导密码，不需要也不建议穷举；
- 注意页面之间的联系，逐步还原完整故事。

## 项目特色

- 使用 HTML、CSS 和原生 JavaScript 构建，无需游戏引擎；
- 还原 Windows XP、旧版 QQ、QQ 空间和早期中文互联网的视觉体验；
- 将邮件、社交平台、新闻、医院和校园档案组合成可探索的叙事空间；
- 通过密码、时间线和跨页面信息关联推动剧情，而不是依赖传统任务列表；
- 包含原创世界观、人物关系、界面设计和多媒体内容。

## 如何运行

项目是纯静态网页，不需要安装依赖。

### 直接打开

下载仓库后，用浏览器打开 `index.html` 即可开始游戏。

### 使用本地服务器（推荐）

在项目目录运行：

```bash
python3 -m http.server 8000
```

然后在浏览器访问：

```text
http://localhost:8000
```

建议使用桌面版 Chrome、Edge 或 Safari，并开启声音以获得完整体验。

## 内容提示

游戏涉及家庭关系、家庭暴力、疾病、死亡及创伤等沉重主题，请根据个人情况决定是否继续体验。

## 开发状态

项目仍在持续完善中，部分界面、文本、线索和平衡可能继续调整。

## English Summary

**Unsent Mail: Recipient Not Found** is a browser-based narrative puzzle game presented through an abandoned Windows XP computer. Players explore emails, chat histories, social profiles, local news, university pages, and public records to solve clue-based passwords and reconstruct a family history that was never openly told. The project is built with HTML, CSS, and vanilla JavaScript and combines retro interface design with nonlinear environmental storytelling.
